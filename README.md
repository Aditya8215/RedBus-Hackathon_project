# RedBus Hackathon Project

Predict the demand (total number of seats booked) for each journey at the route level, 15 days before the actual date of journey (doj).

## Overview

This project aims to build a predictive model to estimate the number of seats that will be booked for each bus journey on a given route, 15 days in advance. It was developed as part of a hackathon challenge.

## Features

- Route-level demand prediction for bus journeys
- Forecasting demand 15 days ahead of the actual journey date
- Designed for data-driven decision making in bus fleet management and route planning
